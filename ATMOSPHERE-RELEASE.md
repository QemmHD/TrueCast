# TrueCast Atmosphere 4.0

16 November 2026. A working upgrade for a personal app and a few friends on GitHub Pages. All sources connected in this release work without an API key. No provider accounts or paid subscriptions were created.

## What changed

- **Future maps:** DWD ICON global precipitation, temperature, 10 m wind and sea-level pressure, with a forecast timeline extending up to 72 hours where fresh source times are available. The interface distinguishes valid time from model-run time and observed radar. Forecast selection is based on advertised source timestamps rather than an invented animation.
- **Observed lightning density:** the public NOAA-derived density product, approximately 8 × 8 km cells over 15-minute periods. This adds genuine lightning activity without claiming individual strikes, nearest-strike distances or Spark parity.
- **Infrared satellite:** NOAA/NESDIS imagery with an observed timeline. Infrared is useful at night; bright cloud patterns do not directly measure rainfall.
- **16-day outlook:** daily forecasts and hourly exploration across the available 16 calendar days, with direct navigation from Today. Nearer hourly windows remain available at 24, 72 and 144 hours. Later forecasts carry increasing uncertainty.
- **Air and allergens:** a 48-hour US AQI timeline, exact-hour exploration, PM₂.₅, PM₁₀, ozone, nitrogen dioxide, dust and six pollen species where CAMS supplies values. Zero is a value; missing data remains unavailable. Pollen coverage is European, not global.
- **Visual redesign:** shaded weather artwork, an atmospheric scene, clearer forecast introductions, distinct map controls, softer surfaces and a compact phone overview. Fahrenheit/dark defaults and iPhone safe areas remain. Daylight belongs with outdoor planning and conditions details.
- **Delivery:** Leaflet is bundled locally with its BSD license. The versioned shell caches 19 required files, including the map library, without depending on a third-party script CDN at startup. Weather APIs and map tiles are not bulk-cached. Deployment hashes the public artifact into the worker cache version, so any changed app asset produces an update automatically.

## Newly connected free spatial sources

### DWD global ICON forecasts

[DWD geoservices](https://www.dwd.de/EN/ourservices/geoservices/geodienste.html), [live precipitation capabilities](https://maps.dwd.de/geoserver/dwd/Icon_reg025_fd_sl_TOTPREC06H/wms?service=WMS&version=1.3.0&request=GetCapabilities), and [DWD copyright](https://www.dwd.de/copyright).

The service advertises global `Icon_reg025_fd_sl_TOTPREC06H`, `T2M`, `UV10M` and `PMSL` products. The app reads their time and `REFERENCE_TIME` dimensions. It requests a selected valid time with an explicit `dim_reference_time` and EPSG:3857 bounds. Metadata is cached for an hour; image requests cover the current viewport rather than pre-downloading a world archive. DWD has no availability guarantee for this public service; attribution remains visible.

Live tests returned PNGs for all four forecast products at future times. An intentionally invalid reference time returned an `InvalidDimensionValue` service exception, confirming that the run parameter is honored. Such exceptions can arrive with HTTP 200, so the app requires the image itself to load before changing the displayed product/timestamp.

The native grid is approximately 0.25°, not street-level. Six-hour precipitation totals overlap when stepped every three hours; they must not be summed as independent windows. The point forecast uses Open-Meteo's regional best match and can differ from the ICON map. Temperature legend boundaries are converted to Fahrenheit when selected. Pressure source contours retain hPa labels; wind uses source barbs rather than invented storm-motion particles.

### NOAA lightning density

[Live service metadata](https://nowcoast.noaa.gov/geoserver/lightning_detection/wms?service=WMS&request=GetCapabilities).

The official product description says the data is a derived/Level 5 NOAA-generated product and **“is appropriate for public distribution.”** It uses NLDN/GLD360 inputs but does not expose the contractor's individual strike data. Values represent strike density per km² per minute, scaled by 10³, over 15-minute periods on an approximately 8 km grid. Main coverage extends from 25°S to 80°N and across the Americas and adjacent oceans (110°E eastward across the date line to 0°). The app labels coverage and never interprets an empty image as an all-clear.

### NOAA infrared satellite

[Live satellite metadata](https://nowcoast.noaa.gov/geoserver/satellite/wms?service=WMS&request=GetCapabilities).

The GMGSI global longwave mosaic combines geostationary satellite inputs. Documentation describes approximately 3 km imagery, hourly products and potential multi-hour latency. Coverage is approximately 60°S–60°N; source bounds and actual availability vary. The app shows advertised observed frames and frame age. It does not shift observed frames into the future or claim that cloud brightness is measured rain intensity.

### CAMS air/pollen outlook

[Open-Meteo air-quality documentation](https://open-meteo.com/en/docs/air-quality-api).

European output is approximately 11 km and global output approximately 45 km, with different model domains. Pollen species are available only from the European forecast. Requests are on demand and cached for 15 minutes; a labeled fallback may be used for up to one hour. Units and null values are preserved. These are model estimates rather than neighborhood sensors or personal medical predictions.

## Validation and remaining boundaries

Fourteen unit scenarios cover refresh and rate limits, source-time expansion, native cadence, stale/future model-run rejection, observed versus future timestamps, DST and missing/zero AQI handling. Browser checks cover direct 16-day/hourly navigation, future-frame requests with explicit model runs, image-load failure retaining the previous product/legend/time, all forecast products, viewport refresh, observed satellite/lightning identity, coverage details, playback pause and the air/pollen timeline. The existing refresh, warning geometry, tropical tracking, responsiveness, offline and worker-upgrade suites remain in place.

Live endpoint checks complement synthetic failure fixtures. These checks establish integration behavior, not a meteorological accuracy ranking. A proper regional provider comparison still needs archived forecasts and independent observations across representative weather. Physical iPhone/Safari and native system features are not certified by Chromium emulation.

Individual-strike proximity alerts, minute-specific rain arrival, raw Doppler/velocity products, global official warnings, native widgets/Live Activities and closed-app monitoring remain separate integrations. iPhone can suspend a PWA while hidden; TrueCast rechecks when the user returns. The personal free stack does not require paid infrastructure, but public services still have attribution, fair-use and availability limits.
