Offline use & updates

After your first online visit, the app shell and last forecast can open offline. Fresh weather, search, alerts and maps need internet access. Background weather notifications are not available.

Updates arrive through this same app. Reopen while online to load the latest release.

Install TrueCast

iPhone & iPad

  1. Open TrueCast in Safari.
  2. Tap Share (or Menu, then Share).
  3. Choose Add to Home Screen. Keep Open as Web App enabled if shown.
  4. Tap Add.

Android

In Chrome, open the menu and choose Install app or Add to Home screen.

Computer

In Chrome or Edge, look for the install icon in the address bar or choose Install TrueCast from the browser menu. Other browsers can use TrueCast as a website.

Your browser decides which installation options are available. Home Screen installation is separate from an App Store or Google Play listing.
